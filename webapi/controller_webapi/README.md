# Fox Web API Controller Sample

Fox Web API 가 제공하는 ASP.NET Core Web API Controller 샘플입니다.

Fox Web API 는 Fox Biz/Data Service 를 HTTP/JSON 기반으로 원격 클라이언트가 호출할 수 있도록 지원하는 일련의 프레임워크 입니다. Fox Web API 는 ASP.NET Web API Controller 를 사용할 수도 있고 Mimimal Web API 를 사용할 수도 있습니다. 이 예제는 컨트롤러 기반의 Web API 를 구현하는 샘플입니다.

상세한 내용은 다음 문서들을 참고 하십시요.

* [Fox Biz/Data Service 개요](https://doc.neodeex.net/webapi/)

* [Fox Web API 개요](https://doc.neodeex.net/webapi/api/)

* [Fox Web API Controller](https://doc.neodeex.net/webapi/api/controller/)

* [Fox Web API Dispatcher (Mimimal Web API)](https://doc.neodeex.net/webapi/api/dispatcher/)
